# Android SecureConnect — бесплатная сборка APK через GitHub Actions

В репозитории находится **checker**, а полный Android-проект пока содержится
только в переданном владельцу архиве `SecureConnect-2.4.6-GitHub-Live-Feed-Code-on-the-go.zip`.
**До загрузки исходников APK в GitHub собрать невозможно.**

## Один раз загрузить исходники с телефона

1. Скачайте ZIP с полным проектом из чата ChatGPT.
2. В репозитории откройте папку `android` и загрузите ZIP через **Add file → Upload files** (в мобильном браузере при необходимости включите «Версия для ПК»).
3. Назовите его строго `source.zip` и сохраните в `main`, то есть путь должен быть `android/source.zip`. Содержимое должно иметь корневую папку `SecureConnect-2.4.6/`, переупаковывать ZIP не надо.
4. Откройте **Actions → Build SecureConnect Android debug APK**. Загрузка автоматически вызовет workflow по событию push.
5. Дождитесь завершения, откройте успешный run → **Artifacts** → `SecureConnect-2.4.6-debug-apk`. Скачайте ZIP артефакта и извлеките `app-debug.apk`.

Это **debug APK**, подписанный временным отладочным ключом CI. Подпись может изменяться от сборки к сборке: для обновления поверх установленной версии Android иногда потребуется удалить предыдущую установку, что может удалить данные приложения. Для релиза нужен отдельный приватный keystore, который нельзя публиковать в GitHub. Публикация исходного ZIP сделает Android-код публичным; **не загружайте ZIP с приватными ключами, токенами или подписками**.

## Проверки

Workflow запрашивает SDK 36, использует JDK 21, оригинальный Gradle Wrapper 9.6.1, скачивает Xray AAR со строгой проверкой SHA-256, выполняет `assembleDebug` и `testDebugUnitTest`, сохраняет APK как GitHub Actions artifact на 7 суток. Никакой платный VPS или API не нужен.

GitHub Actions для публичного репозитория предоставляет бесплатные стандартные runners при соблюдении политики GitHub. Динамическое тестирование VPN на телефоне и поведение мобильного оператора сборкой не подтверждаются.
