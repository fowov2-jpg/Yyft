# VipineshkaVPN 2.4.8 Stable: encrypted recovery cache

Экспериментальный HTTP Payload / TLS Tunnel генератор и интерфейс HTTP CONNECT удалены из Android-сборки и из исходников ветки. Подключение — существующий штатный Xray через Android VpnService.

## Поведение
- Основной AUTO пробует до 4 кандидатов текущего каталога и строгого YouTube/скоростного пула.
- Только если подключение не подтверждено живым Xray HTTPS/TLS, дополнительно пробует до 3 сохранённых ранее успешных VPN-конфигураций.
- Хранит до 12 конфигураций со временем проверки (30 суток) в AES-GCM через Android Keystore. Ни пароли, ни конфигурации в диагностику или GitHub не отправляются.
- После неудачи конфигурация не удаляется, но получает 15-минутный cooldown; при следующем живом HTTPS-успехе сбрасывается счётчик отказов.
- **Кэш = кандидаты на восстановление, а не горячий резерв.** Каждая попытка проходит заново DNS/TCP/Xray и HTTPS с проверкой доверия. TLS-risk сервера исключены; Kill Switch, STOP и текущие настройки фильтра приложений не изменены.
- Строгий пул 21 сервера с двумя тестами скорости/YouTube остаётся отдельным и не заполняется фиктивными результатами.
- Если каталог временно пуст, AUTO может использовать сохранённый конфиг вместо ожидания GitHub.
- Нет фоновых бесконечных HTTP Payload-переборов, дополнительных сервисов или бесконечных тестов скорости.

## GitHub CI
CI распаковывает официальный source.zip ветки и применяет существующие устойчивые патчи, затем apply_stable_recovery.py. Выполняет assembleDebug, testDebugUnitTest, lintDebug, аудит разрешений, подписи APK, загрузку полного ZIP исходников.

## Как открыть ZIP
Распакуй ZIP проекта, открой папку VipineshkaVPN через Android Studio > Open, установи JDK 21 и SDK 36, выполни Gradle Sync, затем :app:assembleDebug.

## Ограничения
CI не воспроизводит российский мобильный оператор; реальные сайты через Android TUN, утечки IP/DNS и температура Xiaomi проверяются на физическом устройстве. Сохранённый сервер может перестать работать в любое время и не гарантирует обход белых списков.
